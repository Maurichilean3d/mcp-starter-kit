    Mejorar un MCP: 
    
    
    Se hace un respaldo, opencode amplía el MCP sin quitarle lo que ya tiene y, si algo sale mal, se restaura el respaldo automáticamente. También se actualizan sus lanzadores (abrir/cerrar).
    
    
    
    
    
    
    
      
      
    
    
  
    

  
    
    
    Combinar varios MCP en una suite
    
    
    Une 2 o más MCP ya creados para que opencode los use a la vez (por ejemplo, dibujar en una app y llevar el resultado a una presentación). Se crea un lanzador que abre todas las apps y opencode juntos.
    
    
    Necesitas al menos dos MCP creados.
